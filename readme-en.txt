■ Greetings ■

Thank you very much for downloading "Rider" Ver2, a motorcycle courier
racing game created by our company.

The prototype of "Rider" was actually a program we created for a certain
project. Unfortunately, that project was canceled and only the prototype
remained.
Later, taking advantage of the renewal of our website, we thought about
making this prototype available for everyone to use. We made a few
modifications and completed it as freeware.
Then, with the cooperation of "Bike Kyubin", a real motorcycle courier
company, we exhibited the game at Tokyo Game Show 2005.
Taking this opportunity, we updated the game and created the current Ver2.

However, since it was originally a prototype and the update was done in a
short period of less than half a year after the release of Ver1, the level
of polish is not ideal and there are still some imperfect aspects in certain
scenarios. We ask for your understanding.
Regarding bugs and errors, we have provided a bulletin board, so we would
appreciate it if you could report them there. We apologize in advance, as
there may be cases where responses are delayed or where it is not possible to
reply.
Additionally, please understand that we do not accept inquiries by phone.

■ Installation ■

Place the downloaded "Setup.exe" file in an appropriate folder and double-
click it.
If you do not change the installation location, a folder named  will
be created inside the same folder as "Setup.exe", and the game will be
installed there.
When extraction is complete, "Rider.exe", the  folder, and "Sound.dll"
will be created inside the  folder.
With this, basic preparation is complete.
There is one point you should be careful with:
If the attribute of the  folder is set to "Read-only", the game will
not function properly. Make sure to uncheck the "Read-only" option in the
folder attributes before using it.
"Rider" was developed with consideration for your environment and does not
use the system registry.

---

■ Uninstallation ■

Removing "Rider" Ver2 is simple. Since it does not use the system registry,
simply delete the entire  folder where the program is stored to
remove it without leaving any impact on your environment.
The game will not appear in "Add or Remove Programs" in the Control Panel.
Perform manual removal using the method above.

■ How to Start ■

Double-click Rider.exe. A small launcher menu containing the freeware
confirmation document will open.
The game is started by pressing the "Game Start" button located in the middle
of this screen.
On this screen, you can also check graphic performance information and access
link buttons to the Crest homepage.
Clicking the "Game Start" button will change the screen and advance to the
delivery slip format menu.

---

■ How to Exit ■

・On the delivery slip menu screen, exit using the "Exit" button in the bottom
right corner of the screen.

・In the bike selection menu, the "ESC" key returns to the delivery slip menu
screen.

・During riding in the game, the "ESC" key pauses the game and displays the
message "Exit Yes/No".
If you press the "Y" key on the keyboard here, you will return to the delivery
slip menu.
If you press "N", the game will resume from the paused state.

■ How to Operate Each Screen ■

1. Launcher Menu
Advances to the next delivery slip menu via the "Game Start" button in the
middle of the screen.
The upper part of the menu displays the freeware confirmation document.
The lower part of the menu displays graphic information for your equipment.
2. Delivery Slip Menu
① Past History
Displays the status of completed deliveries.
The "OK" button returns to the delivery slip menu.
② Various Settings
・BGM (Music)
Allows you to enable/disable music and specify its volume.
・Sound Effects (engine sound, etc.)
Allows you to enable/disable sound effects and specify their volume.
・Reset User Data
Resets game information completed so far and restarts from the beginning.
Select "Yes" and press the "Update" button.
・Screen Mode
You can select Window / FullScreen.
Window mode is a debugging screen, so operation may become unstable.
We recommend using FullScreen whenever possible.
③ Departure
Pressing the departure button advances to the next bike selection screen.
④ Exit
Exits "Rider".
3. Bike Selection
On this screen, available bikes are displayed. Bikes with closed shutters
cannot be used.
Moving the mouse over a bike image will make it start rotating. If you click
in this state, the game will start with that bike.
There are a total of 6 bikes that appear in this game. Use the [→] or [←]
buttons to display other bikes that do not fit on screen.
Additionally, bikes labeled "Scrapped" on the shutter are those whose damage
exceeded the limit and became unusable.
If you do not exceed the limit during the game, the bike will be automatically
restored to perfect condition for the next delivery.
Only bike number 1 will always have a new unit available for the next delivery,
even if it suffers scrapping damage.
As the scenario progresses, more bikes will become available.
4. Game Screen
How to Operate
When you select the bike to use and click, data loading begins.
After waiting a moment, an animation walking through the virtual city until
mounting the bike will be displayed. When riding begins, the mouse acts as
the handlebars and accelerator/brake.
From then on, except for the "ESC" key to pause, all operations are done with
the mouse.
Note that the game is not compatible with arrow keys or numeric keys.
Mouse control is determined by its position within the green box in the
center of the screen.
Even if the mouse goes outside the green box, it will not reflect movements
beyond that.
The trick is not to move the mouse too abruptly.
The upper half represents accelerator opening, and the lower half is braking
force.
When the mouse is in the acceleration position, the pointer appears as a
yellow triangle; when in the braking position in the lower half, it appears
as a downward blue triangle.
With the middle mouse button, you can check distance. Note that while
checking, you will not be able to see nearby objects.
With the left and right buttons, you can look behind.
※If you turn the handlebars while braking, you can move sideways in place
without moving forward.
(Use this when stuck between objects and unable to move, for example.)
※Sometimes you may get stuck between cars without being able to move; in that
case, cancel the delivery with the "ESC" key and try again.
(Unfortunately, there are cases where this type of situation happens.)

■ Other ■

※Screen Explanation
In the meter box at the top right, there are two horizontal bar meters: bike
position and time.
The top gray bar is the bike position, and the bottom 3-color bar is time.
If the top meter reaches the right edge before the bottom meter reaches the
right edge, you succeed.
Below it, there is a wide bar damage meter, which decreases according to
accumulated damage.
When this meter turns entirely gray, it means bike durability reached 0.

※Where You Can Ride
Places where you can ride are vehicle lanes only. Although it may look like
you can ride on the sidewalk at first glance, game rules prohibit riding on
sidewalks.
Riding in the oncoming lane is not restricted by game rules, but if there is
a police officer on the opposite sidewalk, you may be ticketed.
From Ver2 onwards, elevated roads, intersections, and railroad crossings were
added, but you cannot drive under elevated roads, turn left/right at
intersections, or enter tracks at railroad crossings.

※Riding Precautions
Speed limit signs are posted in various places. If you ride above the speed
limit and there is enforcement, you will be ticketed and forced to stop,
causing time loss.
In addition, you must obey traffic lights. Running red lights when a police
officer is present results in being ticketed and forced to stop, losing time.

※Bike Damage
Bike damage is calculated based on relative speed to the collided object.
If damage from a single collision exceeds a certain value, you will restart
from the shoulder, resulting in time loss.
Damage accumulates and, if it exceeds bike durability, that delivery fails.
Furthermore, the bike will be scrapped and cannot be used again.

※Game Over (Delivery Failure)
There are 2 types: excess bike damage mentioned above and running out of time
(Time Over) by not reaching the destination within the specified time.
Also, if excess speed during enforcement exceeds 50 km/h, it is an instant Game
Over and you return to the menu screen.

※Delivery Success
Reaching the destination within the specified time while keeping bike
durability above 0 is considered a success.
Upon success, you can advance to the next delivery.

※End of Game
Upon completing all deliveries, staff credits will be displayed and the game
ends.
From the delivery slip menu, selecting various settings and performing "Reset
User Data" allows you to restart from the beginning again.
